# Task 4 — Sentiment Analysis Using NLP

## Project overview
This project classifies short customer reviews as **positive** or **negative** using Natural Language Processing (NLP).

## Workflow
1. Load and explore text data
2. Clean and preprocess text
3. Convert text into TF-IDF features
4. Train a Logistic Regression classifier
5. Evaluate using accuracy, precision, recall, F1-score and a confusion matrix
6. Predict sentiment for new reviews

## Requirements
- Python 3
- pandas
- matplotlib
- scikit-learn
- Jupyter Notebook

Install dependencies:

```bash
pip install pandas matplotlib scikit-learn notebook
```

## Run the notebook
Open `Task_4_Sentiment_Analysis.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or Google Colab and run all cells.

## Dataset note
The notebook includes a small example dataset so it runs without downloading external data. It demonstrates the workflow and is not intended to show production-level performance. Replace it with a larger real-world labelled reviews dataset for a stronger project.
